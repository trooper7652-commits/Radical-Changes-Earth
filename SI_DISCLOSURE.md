# AI ("Super Intelligence") use disclosure

NASA Space Apps 2026 asks teams to state where and how they used AI. This is the Radical changes team's disclosure. The detailed, dated log is in `SI_LOG.md`.

## What is the team's own work (no AI)

- **The idea:** turning NASA's night-lights visualization into a song so people with low vision can hear how light pollution is changing.
- **The six measurements and what each one controls in the music** (main color's distance from red → rhythm; main color vs each column's average → melody pitch and key; vibrancy and the size of change → tempo; happiness → major or minor; uniqueness → note length; contrast → instruments), all their definitions, thresholds, and the 1–100 scaling.
- **The data choice:** NASA SVS 5313 and the 7 frames at 0, 3, 6, 9, 12, 15 and 18 seconds.
- **The website direction** (picked from three AI-made mockups), the front-page quote, and how the video lines up with the music.

AI was not used to come up with the idea of how to solve the challenge. Claude was instructed to only ask the team questions and never propose project ideas; the full question-and-answer record is in `docs/decisions/grill-log.md`.

## Where AI was used

| Area | Tools | What they did |
|---|---|---|
| Planning | Claude Opus 5.5 (Claude Code) | Asked the team questions, recorded the answers, measured the frames, and wrote the design and plan documents from the team's answers |
| Research | Claude Sonnet 5.5, Claude Haiku 5.5 | Looked up sonification methods, data and testing sources, sound-sample licenses, and checked design tools for safety |
| Code | Claude Fable 5.2, Claude Sonnet 5.5, Claude Haiku 5.5, and one free model via the FreeLLMAPI "line cook" chain (exact provider model not recorded) | Wrote the Java analyzer, the JSON writer, the in-browser player, the offline renderer, the video build script, the website and the tests, from the team's rules |
| Reviews | Claude Fable 5.2, Claude Sonnet 5.5, Claude Opus 5.5 | Reviewed every task against the team's design |
| Website design | Claude Sonnet 5.5 with design skills | Made three visual mockups (the team chose one) and built the page; all graphics are CSS/SVG code written with AI assistance |
| Documentation | Claude Opus 5.5 | Drafted the docs, this disclosure, and the AI log |

### Implementation choices made by AI (not the team's rules)

Where the team's rules left a technical detail open, the AI builder chose it and the team reviewed it: brightness = HSV value; one copy of the world (pixels 1920-5760 of each frame); printed labels masked before measuring; "main color" = most common color after rounding each channel to 16 levels; the bright spot for uniqueness = largest connected bright area vs a ring around it; 32 column groups for the melody measurement; tempo range 60-160 BPM; two octaves for the melody; bass on every 4th beat; how "more offbeat" is spread across notes; note lengths; a volume limiter and end fade; holding each frame on screen during its music (chosen by the team).

## Media

- **Audio:** the song is generated by code (Java analysis + Tone.js playback) that was written with AI assistance. No generative-AI audio model made any sound. To be safe, the demo video's file metadata and description say: "Music generated by code written with AI assistance; see SI_DISCLOSURE.md."
- **Video visuals:** NASA Scientific Visualization Studio frames (SVS 5313); not AI-generated.
- **Instrument sounds:** recorded samples (VSCO 2 Community Edition, CC0; Salamander Grand Piano by Alexander Holm, CC BY 3.0); not AI-generated.
